# py-charm-misc-project

一个用 Python 写的**数字奇偶小游戏**：随机生成一串不重复的数字，数出它的逆序数并判断奇偶；再随机交换其中两个数字，重新判断一次。

## 运行

```bash
python main.py
```

只依赖 Python 标准库（`random`），无需安装任何第三方包。建议 Python 3.8+。

## 玩法

程序每次运行会：

1. 随机生成长度 3–9 的一串**互不重复**的数字；
2. 计算这串数字的逆序数（`num_size`），按奇偶输出「偶」或「奇」；
3. 随机交换两个位置的数字；
4. 再算一次逆序数并输出奇偶。
